# Artifact-Level DSS Evaluation

The evaluation is artifact-level: it checks whether the implemented cockpit records decision inputs, exposes conditional uncertainty, carries rule assumptions into an auditable recommendation, and regenerates its outputs. It is not a user study and does not report organizational performance.

| criterion                       | operational_metric                                                               | result        | interpretation                                                                                      | limitation                                                                               |
|:--------------------------------|:---------------------------------------------------------------------------------|:--------------|:----------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
| decision relevance              | 6 required decision inputs recorded / 6 required inputs                          | 6/6           | All required inputs are represented in the portable configuration.                                  | Input presence does not establish that a local decision objective is valid or complete.  |
| uncertainty transparency        | width, class, warning, and evidence boundary present / 4                         | 4/4           | The report makes conditional uncertainty and non-recovery boundaries visible.                       | Visibility is not a measured user-comprehension outcome.                                 |
| recommendation interpretability | recommendation, rationale, warning, accountability record / 4                    | 4/4           | The artifact makes a bounded conditional action traceable to its assumptions.                       | No intended user has rated clarity, usefulness, or workload.                             |
| robustness awareness            | rule type, judge-save assumption, tie assumption, RRI label / 4                  | 4/4           | A reader can inspect which rules drive a conditional recommendation.                                | The available RRI does not exhaust all institutional configurations.                     |
| disclosure-cost awareness       | conditional disclosure recommendation plus explicit non-measurement boundary / 2 | 2/2           | The artifact distinguishes modeled information reduction from stakeholder outcomes.                 | Privacy, burden, trust, and cost have not been measured.                                 |
| rule-design usefulness          | illustrative cockpit demo plus structurally different synthetic testbed pass / 2 | 2/2           | The same artifact logic can be exercised in an illustrative demo and a different synthetic setting. | This is not evidence that a real institution adopted or benefited from a recommendation. |
| reproducibility                 | focused and repository tests passed                                              | 69 passed     | The artifact can be regenerated from its configuration and stage script.                            | A clean-environment archival release and source-term review remain author tasks.         |
| implementation feasibility      | demo artifact runtime <= 30 seconds                                              | 0.027 seconds | The deterministic demonstration completed within the stated local artifact budget.                  | Runtime on larger fields and deployment integration were not evaluated.                  |

The accompanying radar figure visualizes deterministic evidence-completeness checks. It must not be read as perceived usefulness, decision quality, adoption, trust, or an empirical score assigned by users.
