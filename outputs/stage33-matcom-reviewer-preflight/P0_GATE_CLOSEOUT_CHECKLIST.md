# MATCOM P0 Gate Close-Out Checklist

This checklist closes the two external gates identified by the Stage 33 local
reviewer preflight. It is intentionally a worksheet: portal labels, author
metadata, DOI, release tag, and portal-PDF observations must be filled with
verified values by the corresponding author. No value should be guessed.

## Gate F01: Corrected Release, Archive, DOI, and SHA-256

### Release identity

- [ ] Re-run the Stage 32 generator and Stage 33 preflight from the project root.
- [ ] Confirm the terminal result remains `DO_NOT_SUBMIT_UNTIL_EXTERNAL_GATES_CLOSE`.
- [ ] Confirm the release contains only the corrected Stage 32 manuscript,
  evidence, reproducibility scripts, tracked inputs, and required dependency
  metadata. Do not include Stage 31.5 manuscript or stale Stage 31.5 tables.
- [ ] Create a clean release commit from a clean checkout. Do not tag the
  existing dirty working tree or the Stage 26AA snapshot directly.
- [ ] Create a versioned tag, for example `matcom-stage32-v1.0.0`, only after
  the release contents and generated hashes have been reviewed.

### Conditional upload mapping

Use the mapping that matches the live portal, not a presumed template:

| Portal requirement | Candidate file or action |
| --- | --- |
| Separate title page | `MATCOM_title_page.docx` |
| Manuscript without embedded figures | `MATCOM_main_manuscript.docx` |
| Separate captions | `MATCOM_Figure_Captions.txt` |
| Highlights | `MATCOM_Highlights.docx` or `MATCOM_Highlights.txt`, according to the slot's accepted format |
| Cover letter | `MATCOM_cover_letter.docx`, or paste the source text into the portal field |
| Separate figures | Upload the requested PDF or TIFF files; do not upload both sets unless the portal explicitly requests both |

The current main manuscript contains Word-native tables and equations but no
embedded figure drawing objects. If the portal requires figures embedded in the
manuscript, stop and create an explicitly embedded Stage 32 derivative, then
rerun the full local audit before uploading it.

### Author metadata confirmation

Confirm against the title page and each author's own records:

- [ ] Author order: Lizhen Deng; Yuxin Liu; Bo Li, unless the authors jointly
  approve a documented change.
- [ ] Full names, affiliations, email addresses, and ORCID iDs.
- [ ] Corresponding-author designation and address.
- [ ] CRediT roles.
- [ ] Competing-interest declaration.
- [ ] Generative-AI declaration, if required by the portal.
- [ ] All authors have approved the exact manuscript and the final portal PDF.

### Portal-generated PDF inspection

Download the PDF generated by Editorial Manager and record its filename,
timestamp, and SHA-256. Inspect every page visually and verify:

- [ ] All five editable tables are present, numbered once, and not split in a
  way that loses headers, footnotes, or rows.
- [ ] Equations render as mathematical notation rather than raw TeX, with no
  clipped subscripts, superscripts, braces, or special symbols.
- [ ] Figure numbering and captions are one-to-one and in order.
- [ ] Figures are not blank, low-resolution, rotated, or detached from their
  captions.
- [ ] References are complete and not duplicated or truncated.
- [ ] No title-page author metadata has leaked into an anonymized manuscript
  slot when the selected review model prohibits it.
- [ ] No page contains overlapping text, tables, figures, or captions.

## Closure rule

F01 is closed only when the public release, persistent DOI, release commit,
and release SHA-256 are independently verifiable. F02 is closed only when the
five portal facts, author metadata, upload mapping, and portal-generated PDF
inspection are recorded. Until both gates are closed, the submission decision
remains `DO_NOT_SUBMIT`.
